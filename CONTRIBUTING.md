# Contributing to prompt-template-builder

Thank you for your interest in contributing to `prompt-template-builder`! We welcome high-quality contributions, bug fixes, feature proposals, and documentation improvements.

## Code of Conduct

We maintain an inclusive, welcoming environment. Please be respectful and constructive in all issue discussions and pull requests.

## Getting Started

1. Fork the repository on GitHub.
2. Clone your fork locally:
   ```bash
   git clone https://github.com/YOUR_USERNAME/prompt-template-builder.git
   cd prompt-template-builder
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Run tests:
   ```bash
   npm test
   ```

## Development & Pull Requests

- Keep dependencies at zero.
- Ensure all tests pass and add new unit tests for any new features or bug fixes.
- Run `npm run lint` to verify TypeScript types compile cleanly.
- Write clear, concise commit messages.
